S1 - Single Static Obstacle Benchmark (20 cases)

공통 조건
- 200 m x 200 m benchmark world 안에서 사용
- Case마다 Start / Goal / 주행 방향 / 거리 / 장애물 위치 / 형상 / 크기 / yaw가 모두 다름
- 모든 Case의 공통점은 '단일 정적 장애물 1개를 기본적으로 우회해야 한다'는 것뿐임
- 일부 Case는 roll / pitch가 0이 아니어서 장애물이 3D로 약간 기울어져 있음
- polygon은 임의의 2D 점들을 위로 extrusion하는 형상을 의도함
- pose에는 z를 넣지 않음. 향후 case_spawner.py에서 geometry와 roll/pitch를 보고 지면 접촉 높이를 계산할 예정
- cylinder의 yaw는 형상상 의미가 거의 없지만 pose 형식을 통일하기 위해 기록함

중요
- S1은 100 m 미만의 다양한 거리로 구성.
- S6는 별도로 모든 Case에서 시작점-최종 목표점 거리를 100 m 이상으로 설계.
- 이 파일들은 '시험 정의'이며, benchmark.sdf 자체에는 장애물을 고정해서 넣지 않음.
