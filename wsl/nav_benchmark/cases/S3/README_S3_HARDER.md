# S3 Harder v3

S3_01~05는 기존 그대로 유지한다.
S3_06~20만 다중장애물 배치를 더 어렵게 변경했다.

변경 방향:
- 단순 좌/우 번갈이 배열 제거
- nominal centerline을 직접 막는 장애물 추가
- 장애물 간격을 불규칙하게 구성
- 짧은 compound cluster / staggered doublet 포함
- 큰 장애물 뒤 짧은 거리 내 다음 장애물 배치
- box / cylinder / polygon 혼합
- S4와 겹치지 않도록 '좁은 통로를 통과하는 것' 자체가 핵심이 되도록 만들지는 않음

S3의 목적은 여전히:
계획 -> 회피 -> 경로 복귀 -> 다음 장애물 대응
을 여러 번 연속 수행하는 안정성 평가.
