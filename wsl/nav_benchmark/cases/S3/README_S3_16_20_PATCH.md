# S3_16~20 harder patch v4

S3_01~15는 그대로 유지하고 S3_16~20만 재설계했습니다.

- 진행선 주변 일렬 배치 대신 좌우 약 ±3~5 m까지 장애물을 분산
- 중앙 차단물 + 측면 장애물 + 비대칭 클러스터 조합
- 한 번 우회한 뒤 같은 방향을 유지하면 다음 장애물 때문에 다시 경로를 바꾸게 구성
- box / cylinder / polygon 혼합
- S4와 겹치지 않도록 '좁은 통로 폭 자체'를 한계 조건으로 만들지는 않음

목적은 넓은 2D 장애물 필드에서 연속적인 계획/회피/재계획 안정성을 평가하는 것입니다.
